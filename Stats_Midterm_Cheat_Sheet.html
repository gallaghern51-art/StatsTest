§1 Probability Foundations

Vocabulary

  • Experiment → process with chance outcomes. Sample space (S) = set of all outcomes. Event = a subset of outcomes (capital letters A, B, …).
  • Simple events = the most basic, mutually-exclusive outcomes; S is the collection of all of them. Ex: two coins → S = {HH, HT, TH, TT}.
  • Mutually exclusive = both cannot happen at once (A∩B = ∅).
  • Intersection A∩B = both occur. Union A∪B = A or B or both.

The Core Probability Rules

Range & total0 ≤ P(A) ≤ 1  ·  P(S) = 1  ·  Σ p(all outcomes) = 1
ComplementP(A) = 1 − P(A)
Equally-likely outcomesP(A) = m / M  (m favorable of M equally-likely)
Addition (general)P(A∪B) = P(A) + P(B) − P(A∩B)
Addition (mutually excl.)P(A∪B) = P(A) + P(B)
MultiplicationP(A∩B) = P(A|B)·P(B) = P(B|A)·P(A)
Independent eventsP(A∩B) = P(A)·P(B)

Conditional Probability & Independence

ConditionalP(A|B) = P(A∩B) / P(B)

Independence test — A, B independent iff any one holds:

P(A|B) = P(A)  ⇔  P(B|A) = P(B)  ⇔  P(A∩B) = P(A)P(B)
methodTo decide independence: compute P(A)·P(B) and compare to the given P(A∩B). Equal → independent; not equal → dependent.
trapMutually exclusive ≠ independent. If A, B are mutually exclusive with P>0 they are dependent (knowing A happened forces P(B)=0). Conditioning shrinks the sample space.

Total Probability & Bayes' Theorem

Law of total probabilityP(A) = P(A|B)·P(B) + P(A|B)·P(B)
Bayes' theoremP(B|A) = P(A|B)·P(B)⁄P(A|B)·P(B) + P(A|B)·P(B)
methodTwo-stage / "jar" & testing problems: Stage 1 = which path (die roll, coin, jar). Stage 2 = outcome given the path. Multiply along a branch; add branches for total probability; Bayes to reverse (find the cause given the effect). A tree or a frequency table scaled to 10,000 both work.
Ex · Disease test (Bayes)

P(Dis)=.01, P(Pos|Dis)=.98, P(Neg|Dis)=.99 ⇒ P(Pos|Dis)=.01. Find P(Dis|Pos).

P(Dis|Pos)= (.98)(.01) / [(.98)(.01)+(.01)(.99)] = .0098/.0197 = ≈ .498

Table of 10,000: 98 true-pos, 99 false-pos → 98/197 = .498.

Contingency (Two-Way) Tables

Joint = one cell ÷ grand total. Marginal = row/col total ÷ grand total. Conditional = cell ÷ that row-or-column total (the "given" resets the denominator).

§2 Counting: Factorials, Permutations, Combinations

Factorialx! = x(x−1)···(2)(1)  ·  0! = 1
Permutations — order MATTERSnPk = n! / (n−k)!
Combinations — order DOESN'TC(n,k) = (nk) = n! / [ k!(n−k)! ]
  • Order x distinct items in a row → x!
  • Pres/VP/Treas from 10 (order matters) → 10·9·8 = 720 = 10!/7!
  • Committee of 3 from 8 (no order) → C(8,3) = 56
  • Choose 2 of 5 firms, P(they're A&B) = 1/C(5,2) = 1/10; P(E among 3 chosen of 5) = C(4,2)/C(5,3) = 6/10 = 3/5
method"Arrange / rank / assign titles" → permutation. "Choose / select / committee / sample" → combination.

§3 Random Variables: PMF, E(X), Variance

Definitions

  • Random variable (X) = takes numeric values by chance. Discrete = countable ("counting"); Continuous = measured, in-between values.
  • PMF / pdf: p(x)=P(X=x). Requires 0 ≤ p(x) ≤ 1 and Σ p(x) = 1.
  • CDF: F(x)=P(X≤x). Then P(X>x)=1−F(x); P(a≤X≤b)=F(b)−F(a−1) for integers. Get pmf from cdf by differencing.

Expected Value & Variance

Mean / expected valueμX = E(X) = Σ x·p(x)
Variance — definitionσ²X = Var(X) = Σ (x − μ)²·p(x)
Variance — shortcut (use this!)Var(X) = Σ x²·p(x) − μ² = E(X²) − [E(X)]²
Standard deviationσX = √Var(X)  (always ≥ 0; in original units)
methodBuild a table: columns x, p(x), x·p(x), x²·p(x). Sum col 3 → E(X). Sum col 4 → E(X²). Var = E(X²) − [E(X)]².

Rules for E and Var (a, b constants)

E(a) = a
E(aX+b) = a·E(X) + b
E(X+Y) = E(X)+E(Y) always
Var(a) = 0
Var(aX+b) = a²·Var(X)
σaX = |a|·σX
trapAdding a constant b shifts the mean but NOT the variance (Var(X+b)=Var(X)). A multiplier a comes out squared in variance (a²) but plain in the mean.
method · empirical rule for RVs≈⅔ of values within μ±σ; ≈95% within μ±2σ.

§4 Covariance, Correlation & Sums of Random Variables

CovarianceCov(X,Y) = E(XY) − μXμY = E[(X−μX)(Y−μY)]
Correlation (−1 ≤ ρ ≤ 1)ρXY = Cov(X,Y) / (σX·σY)  ⇒  Cov(X,Y) = ρXY·σX·σY
E(XY)E(XY) = Σ (x·y)·P(x,y)  sum over joint outcomes

Variance of a Sum / Combination

Two variablesVar(X+Y) = Var(X)+Var(Y)+2·Cov(X,Y)
DifferenceVar(X−Y) = Var(X)+Var(Y) − 2·Cov(X,Y)
General weightedVar(aX+bY) = a²Var(X)+b²Var(Y)+2ab·Cov(X,Y)
Scaling covarianceCov(aX,bY) = ab·Cov(X,Y)  ·  Cov(X,X)=Var(X)
independent ⇒ Cov = 0Then Var(X+Y)=Var(X)+Var(Y) and Var(X−Y)=Var(X)+Var(Y) too. Variances add; standard deviations do NOT (σX+Y ≠ σX+σY).
Ex · Covariance drill

σX=10, σY=12, σZ=20; ρXY=.8, ρXZ=−.5.

Cov(X,Y)=.8·10·12=96; Cov(X,Z)=−.5·10·20=−100; Cov(2X,3Y)=6·96=576.

Var(X+Y)=100+144+2(96)=436. Var(3X+5Z)=9(100)+25(400)+2·15(−100)=7900.

Ex · Portfolio (weights sum to 1)

Return = w1X + w2Y. w=.4/.6, E=.12/.19, σ=.09/.28, ρ=−.4.

E(R)=.4(.12)+.6(.19)=.162

Var=.4²(.09²)+.6²(.28²)+2(.4)(.6)(−.4)(.09)(.28)=.0247 → σ=.157

Negative ρ lowers portfolio risk — the diversification effect.

§5 The Named Discrete Distributions

Binomial (n, π) — fixed # of independent trials

Use when: n fixed trials · each success/fail · constant π · independent (sampling WITH replacement). X = # successes = Y₁+…+Yₙ, a sum of n Bernoulli trials (one trial: E=π, Var=π(1−π)).

P(X=k) = C(n,k)·πk·(1−π)n−k
E(X)=nπ  ·  Var(X)=nπ(1−π)  ·  σ=√(nπ(1−π))

"At least one" = 1 − P(0) = 1 − (1−π)n. Excel: =BINOM.DIST(k, n, π, FALSE) for P(X=k); TRUE for P(X≤k).

Ex · Salesperson, n=25 visits, π=.3

P(8 sales)=C(25,8)(.3)⁸(.7)¹⁷=.165. E=25(.3)=7.5; σ=√(25·.3·.7)=2.29.

Poisson (λ) — random events over time/space

Use when: counting events that occur one-at-a-time, independently, at a steady rate; no upper limit on x.

P(X=k) = e−λ·λk / k!  (k=0,1,2,…)
E(X) = Var(X) = λ  ·  λ = rate × duration
methodScale λ to the window asked: 4/hr over 2 hr → λ=8; over 15 min → λ=1. "At least one" = 1 − e−λ.
Ex · Calls at 4/hr (Poisson)

P(5 in 2 hr): λ=8 → e⁻⁸·8⁵/5!=.0916. P(≥1 in 1 hr): λ=4 → 1−e⁻⁴=.982.

Hypergeometric (N, r, n) — sampling WITHOUT replacement

P(X=x) = C(r,x)·C(N−r, n−x)⁄C(N,n)

N=population, r=successes in pop, n=sample, x=successes in sample. Without replacement (draws not independent) → hypergeometric, not binomial.

Ex · 20 marbles (12 red), draw 5, no replacement

P(exactly 3 red)=C(12,3)·C(8,2)/C(20,5)=.397 (with replacement → Binomial: C(5,3).6³.4²=.346).

Which distribution? — quick selector

SituationModel
Fixed n trials, constant p, w/ replacementBinomial
Draw without replacement from finite popHypergeom.
Events per time/area, steady ratePoisson
Sum/mean of many RVs; large nNormal (CLT)
approxHypergeometric ≈ Binomial when n is small vs. N (pop large): P(none)≈(1−r/N)n.

§6 The Normal Distribution & z-Scores

Properties

  • Continuous, bell-shaped, symmetric about μ. Two parameters: mean μ, variance σ².
  • Only the number of SDs from the mean matters — that's what standardizing captures.
  • Continuous ⇒ P(X=a)=0, so < and ≤ are interchangeable.
StandardizeZ = (X − μ) / σ  →  Z ~ Normal(0, 1)
IntervalP(a ≤ X ≤ b) = P(X≤b) − P(X≤a)
"Find the value" / percentilex = μ + z·σ  (z from the target tail area)

Continuous RV basics

Probability = area under the density curve; any single point has probability 0. Notation X ~ N(μ, σ²) (2nd parameter is the variance). Uniform on [1,5]: height = 1/(5−1) = ¼ → P(2≤X≤4)=2·¼=½.

Reading the class z-table

This course's table gives A(z)=P(0≤Z≤z) (area from the middle out). Convert:

  • P(Z≤z) = 0.5 + A(z)  (z>0)
  • P(Z>z) = 0.5 − A(z)
  • P(Z≤−z) = 0.5 − A(z)  (symmetry)
  • P(−a≤Z≤b) = A(a)+A(b)
methodAlways draw the bell, mark μ, shade what's asked, then translate to A(z) pieces. "Find k with P(0≤Z≤k)=.40" → read the table backwards → k≈1.28.

Some tables (& Excel NORM.S.DIST) give the full cumulative Φ(z)=P(Z≤z) directly — then read it straight off, no +.5.

interpolateBetween rows: z ≈ zlo + [(target−Alo)/(Ahi−Alo)]·(zhi−zlo). Ex: Φ=.90 lies between .8997 (1.28) & .9015 (1.29) → k≈1.282.
Ex · X ~ N(100, 10²)

P(92<X<104)=P(−.8<Z<.4)=Φ(.4)−Φ(−.8)=.6554−.2119=.4435

Ex · Coke demand ~ N(150, 20)

P(X≤200): z=(200−150)/20=2.5 → .5+.4938=.9938

P(X≥180): z=1.5 → .5−.4332=.0668

Stock so P(run out)=.1: z=1.28 → 150+1.28(20)=175.6 → stock 176.

§7 Sampling Distributions & the Central Limit Theorem

CLT: the sum (or average) of many independent, identically-distributed RVs is ≈ Normal — even when the underlying variable is not normal. Conditions: iid + independent + large n (rule of thumb n ≥ 30).

SUM of nmean = nμ
SD = σ√n
Z = (T − nμ)/(σ√n)
AVERAGE of n (X)mean = μ
SE = σ/√n
Z = (X − μ)/(σ/√n)
trapSum vs. average. Sum spreads out (σ√n); the average tightens (σ/√n). Pick the right one and don't mix variances with SDs.

Two special cases

  • Underlying is Normal → the sum/average is exactly Normal for any n (not an approximation).
  • Normal ≈ Binomial: valid when nπ > 5 and n(1−π) > 5; then X ≈ Normal with mean nπ, variance nπ(1−π).
the classic exam trap"n>30 ⇒ an individual observation is normal" is FALSE. The CLT normalizes the sample mean/sum only. A single item keeps the population's shape no matter how big n is.
Ex · Cars sold/day: E=1.7, Var=.81 (SUM)

300 days: sum mean=300(1.7)=510, SD=√(300·.81)=15.59.

P(fewer than 495)= z=(495−510)/15.59=−.96 → ≈ .17

Ex · Branch employees μ=50, σ=15 (AVERAGE)

n=40: SE=15/√40=2.37 → z=(55−50)/2.37=2.11 → P(X>55)=.017

n=100: SE=15/√100=1.5 → z=3.33 → P(X>55)=.0004

Bigger n → smaller SE → tighter around μ. Assumes iid, n large.

§8 Descriptive Statistics & Data (Class 01)

Data & sampling vocabulary

  • Quantitative (numbers/arithmetic) vs Qualitative (categories). Discrete (count) vs Continuous (measure).
  • Nominal (no order) vs Ordinal (ordered, e.g. Likert). Cross-sectional vs Time series. Univariate vs Multivariate.
  • Random sample: every element equally likely to be chosen.
key ideaParameter = summary of the population (FIXED). Statistic = summary of the sample (RANDOM). Populations are fixed; statistics vary sample-to-sample.

Center & spread

Sample / pop meanx=Σx/n · μ=Σx/N
Medianmiddle; even n→avg of 2
Population varianceσ² = Σ(x−μ)²/N = (Σx² − Nμ²)/N
Sample variance — divide by n−1s² = Σ(x−x)²/(n−1) = (Σx² − nx²)/(n−1)
why n−1?So s² is an unbiased estimator of σ². Population σ² uses N and μ; sample s² uses n−1 and x. Mixing these up is the classic error.

z-scores, quartiles & outliers

z=(x−μ)/σ or (x−x)/s
  • Outlier by z: |z|≥3 outlier; 2≤|z|<3 possible outlier.
  • Empirical rule (bell-shaped): 68% within μ±σ, 95% within μ±2σ, 99% within μ±3σ.
  • Quartiles: Q1 at position (n+1)/4; Q3 at 3(n+1)/4; IQR=Q3−Q1.
  • Box-plot fences: inner = Q1−1.5·IQR & Q3+1.5·IQR (→ outlier); outer = ±3·IQR (→ serious outlier).
robustnessSensitive to outliers: mean, range, s/σ. Resistant: median, IQR. Bar chart = qualitative (gaps); histogram = quantitative (no gaps).
Ex · Box plot {30,40,70,81,90,118,123}

Q1=70, median=81, Q3=90 → IQR=20. Fences: 70−1.5(20)=40 & 90+1.5(20)=120. Points outside → outliers: 30 & 123; whiskers reach 40 & 118.

Ex · Mean vs. median (n=9 compensations)

86.24, 88.77, 88.95, 94.62, 95.42, 95.60, 95.64, 97.18, 99.80 → median = middle = 95.42; mean = 93.58 (pulled down by the low value — mean < median here).

§9 The Sample Midterm — Fully Worked

The game: Roll a fair die. 5 or 6 → Jar 1 (15 red, 5 green). 1–4 → Jar 2 (8 red, 12 green). So P(5,6)=2/6=⅓, P(1–4)=4/6=⅔; P(G|Jar1)=5/20=.25, P(G|Jar2)=12/20=.6.

P1 · P(green ball) — total probability

P(G)=P(G|Jar1)P(5,6)+P(G|Jar2)P(1–4) = .25(⅓)+.6(⅔) = .0833+.40 = .4833

P2 · P(rolled 5–6 | green) — Bayes

= P(G|5,6)P(5,6) / P(G) = .0833 / .4833 = .1724

P3 · P(rolled 1–4 ∪ green)

= P(1–4)+P(G)−P(1–4∩G) = .6667+.4833−(.6·.6667) = .6667+.4833−.40 = .75

P4 · Distribution of total profit Z=X+Y

Die X: $2 if 5–6, $5 if 1–4. Ball Y: $4 red, $3 green.

P7 · Win $9 ≥ 25× in 100 plays — Binomial ≈ Normal

"Win $9" = roll 1–4 & red, p=.2667. n=100: mean=np=26.67, σ=√(np(1−p))=4.42.

Check nπ,n(1−π)>5 ✓. z=(24.5−26.67)/4.42=−.49 → P(X≥25)=P(Z>−.49)≈.69 (½ continuity correction)

P8 · Var(2X) vs Var(X+Y) · Var=49 each, indep.

Var(2X)=2²·49=196. Var(X+Y)=49+49=98 (Cov=0). → Var(2X) > Var(X+Y)

P9 · Independent? P(A)=.5, P(B)=.3, P((A∪B)ᶜ)=.42

If independent: P(A∩B)=.15 → P(A∪B)=.65 → P((A∪B)ᶜ)=.35. Given .42 ≠ .35 → NOT independent.

P10 · Corn chips: μ=11.95, σ=.22, n=100

(a) P(total > 1194): sum mean=100(11.95)=1195, SD=√100(.22)=2.2. z=(1194−1195)/2.2=−.4545 → P(Z>−.45)=.675

(b) P(x < 11.97): SE=.22/√100=.022. z=(11.97−11.95)/.022=.909 → .818

(c) "n>30 ⇒ individual bag is normal"? No. CLT normalizes the sample mean/sum, not an individual bag — it keeps the population shape for any n.

Top exam traps & final checklist

  • Variances add, SDs don't. Never add standard deviations.
  • Var(aX)=a²Var(X) — square the constant; +b does nothing to variance.
  • Independent ⇒ Cov=0; if a ρ or Cov is given, you MUST include 2·Cov.
  • With replacement→Binomial; without→Hypergeometric.
  • Poisson λ = rate × the exact time window asked.
  • CLT: sum uses σ√n, average uses σ/√n — and it never makes an individual value normal.
  • Sample s² divides by n−1; population σ² divides by N.
  • This class' z-table is "0→z" — add .5 for a full left tail; use symmetry for negatives.
  • Always draw the bell & shade before computing a normal probability.
  • "At least one" = 1 − P(none).
