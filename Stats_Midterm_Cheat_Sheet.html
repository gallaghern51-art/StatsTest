§1 Types of Data & the Big VocabularyClass 1

Sort every variable 4 ways

  • Quantitative = numbers you can do math on (price, temp). Qualitative/categorical = labels (country, brand).
  • Discrete = counted, no in-between (# cars). Continuous = measured, in-betweens exist (gallons, time).
  • Nominal = categories with no order (Ford, Nissan). Ordinal = categories with an order (disagree→agree).
  • Univariate = 1 column. Multivariate = 2+ columns. Time series = order in time matters; cross-sectional = one snapshot.

Population vs Sample (the mental model)

  • Population = ALL items (fixed, usually can't collect). Sample = a subset you actually measure (random).
  • Parameter = a number describing the population (μ, σ) → FIXED. Statistic = a number from the sample (x, s) → RANDOM (changes each sample).
  • Random sample = everyone has an equal chance to be picked → the sample resembles the population.
why it mattersEvery formula later comes in a population version (μ, σ, ÷N) and a sample version (x, s, ÷n−1). Using the wrong one is the #1 silly error.

§2 Describing the CenterClass 1

Mean (average)x = (x₁+x₂+…+xₙ)/n = Σxᵢ/n  (population: μ = Σxᵢ/N)

Median = middle of the sorted list. n odd → the true middle; n even → average of the two middle values. Mode = most frequent value. Trimmed mean = drop top & bottom x%, then average (kills outliers).

mean vs medianThe mean gets dragged by outliers & skew; the median doesn't. Right-skew (long right tail) → mean > median. So median is the "typical" value when data is lopsided.
Example — mean & median (n=9)

Sorted: 86.24, 88.77, 88.95, 94.62, 95.42, 95.60, 95.64, 97.18, 99.80. Median = 5th = 95.42. Sum=842.22 → mean=842.22/9=93.58. Mean < median → slight left pull.

§3 Describing the Spread (Variability)Class 1

Sample variance — divide by n−1s² = Σ(xᵢ − x)² / (n − 1)  ·  s = √s²
Population variance — divide by Nσ² = Σ(xᵢ − μ)² / N · shortcut (Σxᵢ² − Nμ²)/N · σ = √σ²
Recipe · s² by hand
  1. Find x.
  2. Each value: subtract x, then square.
  3. Add all the squares.
  4. Divide by n−1. That's s². Then √ for s.
gotchaSAMPLE ÷ (n−1); POPULATION ÷ N. SD is just √variance — its units match the data; variance units are squared. Variance/SD are never negative.
Example — variance & SD

Data 2,4,6,8 (sample, n=4). x=5. Deviations −3,−1,1,3 → squares 9,1,1,9 → Σ=20. s²=20/(4−1)=6.67, s=√6.67=2.58.

z-score — standardize a valuez = (x − x)/s = (x − μ)/σ → "how many SDs from the mean"

z>0 above avg, z<0 below. Outlier rule: |z| ≥ 3 → outlier; 2 ≤ |z| < 3 → borderline.

empirical rule (68-95-99.7)Only if bell-shaped & symmetric: ≈68% within μ±σ · ≈95% within μ±2σ · ≈99.7% within μ±3σ.

Ex: x=90, μ=75, σ=10 → z=(90−75)/10 = +1.5 (1.5 SDs above avg).

§4 Quartiles, IQR, Box Plots & OutliersClass 1

Positions in the sorted listQ1 at (n+1)/4 · Q2 = median at (n+1)/2 · Q3 at 3(n+1)/4
Spread measuresRange = max − min (outlier-sensitive) · IQR = Q3 − Q1 (outlier-resistant)
Box-plot fences (the outlier test)Inner: Q1−1.5·IQR & Q3+1.5·IQR · Outer: ±3·IQR

Past inner fence = outlier; past outer = serious outlier. Box spans Q1→Q3, line = median, whiskers reach the farthest points still inside the fences; dots beyond = outliers.

Example — box plot {30,40,70,81,90,118,123}

Q1=70, median=81, Q3=90 → IQR=20. Fences: 70−1.5(20)=40 & 90+1.5(20)=120. Outside → outliers 30 & 123; whiskers reach 40 & 118.

histogramsShape shows skew (which tail is long), outliers (isolated bars), bimodal (two humps). A log transform pulls a right-skewed data set toward symmetric. Bar chart = qualitative (gaps); histogram = quantitative (no gaps).

§5 Probability — All 7 Rules, LabeledClass 2

Setup words: Experiment=chance action · Outcome=one result · Sample space S=list of ALL outcomes · Event A=a group of outcomes · Mutually exclusive=can't both happen.

1 Range: 0 ≤ P(A) ≤ 1 (0=impossible,1=sure)
2 Total: Σ P(all simple events) = 1
3 Complement: P(A′) = 1 − P(A) ← best for "at least one"
4 Addition (OR): P(A∪B)=P(A)+P(B)−P(A∩B)
5 Mutually excl.: then P(A∩B)=0, so P(A∪B)=P(A)+P(B)
6 Multiplication (AND): P(A∩B)=P(A|B)·P(B)=P(B|A)·P(A)
7 Independence: P(A∩B)=P(A)·P(B) ⇔ P(A|B)=P(A)

§6 Conditional Probability & IndependenceClass 2 / Handout

Conditional — "A given B"P(A|B) = P(A∩B) / P(B)

You already KNOW B happened → shrink the whole world down to just B, then ask about A.

Independent vs dependent: independent = B happening does not change A's chance, so P(A|B)=P(A) and P(A∩B)=P(A)·P(B). Dependent = it does change it → you must use P(A|B). Test it: compute P(A)·P(B); if it equals the given P(A∩B) they're independent, else not.

Example 1 — two coins

S={HH,HT,TH,TT}, each ¼. A="at least one head"={HH,HT,TH}; B="at least one tail"={HT,TH,TT}. A∩B={HT,TH}. P(A∩B)=2/4=½; P(A∪B)=P(all four)=1.

Example 2 — is it independent?

P(A)=.4, P(B)=.2. If independent: P(A∩B)=.4·.2=.08, P(A∪B)=.4+.2−.08=.52. If instead P(A|B)=.6 ≠ .4 → NOT independent; then P(A∩B)=.6·.2=.12, P(B|A)=.12/.4=.30.

Example 3 — roll two dice (S has 36 equally-likely outcomes)

A="sum is 5", B="first die is 1 or 2", C="sum is 7". Count outcomes over 36:

P(A)=4/36=1/9 · P(B)=12/36=1/3 · P(C)=6/36=1/6 · P(A∩B)=2/36=1/18 · P(A∪B)=1/9+1/3−1/18=7/18 · P(B|A)=P(A∩B)/P(A)=(1/18)/(1/9)=½ · P(C∪B)=1/6+1/3−1/18=4/9 · P(B|C)=(1/18)/(1/6)=1/3.

§7 Trees, Total Probability & BayesClass 2

Total probability — all paths to an eventP(A) = P(A|B)·P(B) + P(A|B′)·P(B′)
Bayes — flip P(A|B) into P(B|A)P(B|A) = P(A∩B)/P(A) = P(A|B)·P(B)⁄P(A|B)·P(B)+P(A|B′)·P(B′)
Recipe · reverse the condition (Bayes)
  1. Bottom = P(evidence) via total probability — add EVERY path that gives the evidence.
  2. Top = the ONE path you're asked about.
  3. Divide: top ÷ all-paths.
Example — jar game (Sample Exam Q1 & Q2)

Die: 5–6→Jar 1 (15R,5G); 1–4→Jar 2 (8R,12G). P(J1)=2/6=.333, P(J2)=4/6=.667; P(G|J1)=5/20=.25, P(G|J2)=12/20=.60.

P(Green)=.25(.333)+.60(.667)=.0833+.40=.4833. P(rolled 5,6 | Green)=.0833/.4833=.1724.

Example — medical test (rare disease)

P(Dis)=.01, P(Pos|Dis)=.98, P(Pos|noDis)=.01. P(Dis|Pos)=(.98·.01)/[(.98·.01)+(.01·.99)]=.0098/.0197=.497. Even a "good" test is a coin-flip when the disease is rare.

Example — coin picks a jar (HW2)

Jar A 7R/3G, Jar B 15R/30G; fair coin (H→A, T→B). P(red)=.5(.7)+.5(⅓)=.517. P(tails|green)=[.5(⅔)]/[.5(.3)+.5(⅔)]=.690.

§9 Counting: Factorials, Permutations, CombinationsClass 2

Factorial = ways to line up n itemsn! = n·(n−1)···1 · 0! = 1 · 4! = 24
Permutation — ORDER MATTERS (ranks, titles)nPr = n! / (n−r)!
Combination — ORDER DOESN'T (a group)nCr = C(n,r) = n! / [r!(n−r)!]
Recipe · don't compute huge factorials
  1. In 10!/7!, the smaller factorial cancels the tail: 10!/7! = 10·9·8 = 720.
  2. For nCr, expand r terms on top, r! on bottom, cancel. Only multiply down to what's left.
P or C?"Rank / title / order / sequence" → Permutation. "Choose / committee / group / hand" → Combination (= permutation ÷ r!). Probability by counting = favorable ÷ total, using the SAME tool top & bottom.
Examples

Pres/VP/Treas from 10 (order): 10P3=10·9·8=720. Committee of 3 from 8: 8C3=56. Pick 2 of 5 firms, P(exactly A&B)=1/5C2=1/10. P(E among 3 chosen of 5)=4C2/5C3=6/10=.6. Excel: =COMBIN(n,r), =PERMUT(n,r), =FACT(n).

§10 Random Variables — PMF & CDF TablesClass 3

A random variable (RV) is a number decided by chance (X, Y, Z). Discrete = countable list (dice sum); continuous = measured (time, weight).

PMF / pdf — probability of each valuep(x) = P(X=x) · needs 0 ≤ p(x) ≤ 1 and Σ p(x) = 1
CDF — running total, "≤"F(x)=P(X≤x)=add p up to x · P(X>x)=1−F(x) · reverse: p(x)=F(x)−F(prev)

§11 Expected Value, Variance & SD of a Discrete RVClass 3

Mean / expected valueμ = E(X) = Σ x·p(x)  (each value × its probability, summed)
Variance — use the shortcutVar(X) = Σ x²·p(x) − μ² = E(X²) − [E(X)]² · SD = √Var
Recipe · E & Var from a table
  1. E(X) = add up x·p(x).
  2. E(X²) = add up x²·p(x).
  3. Var = E(X²) − [E(X)]². SD = √Var.
noteThe probabilities must sum to 1 before you trust E/Var. "Fair value of a gamble / game" = E(X).
Example — coin, X = # heads (from §10)

E(X)=0(⅛)+1(⅜)+2(⅜)+3(⅛)=12/8=1.5. E(X²)=0+⅜+12/8+9/8=24/8=3. Var=3−1.5²=.75; SD=√.75=.87.

§13 Rules for E & Var · Covariance · CorrelationClass 3

Expected value ALWAYS addsE(X+Y)=E(X)+E(Y) (true even if dependent) · E(aX+b)=a·E(X)+b
Variance of a scaled/shifted RVVar(aX+b) = a²·Var(X)  (+b vanishes; a gets squared) · SD(aX)=|a|·SD(X)
Adding RVs — INDEPENDENTVar(X+Y) = Var(X) + Var(Y)
Adding RVs — DEPENDENT (general)Var(X ± Y) = Var(X) + Var(Y) ± 2·Cov(X,Y)
#1 exam trapVARIANCES add, SDs do NOT — never add standard deviations. Watch the sign: Var(X−Y) still +Var(Y) but −2Cov.
CovarianceCov(X,Y)=E(XY)−E(X)·E(Y) · independent ⇒ Cov=0
Correlation (unitless, −1…1)ρ = Cov(X,Y)/(σX·σY) ⇒ Cov = ρ·σX·σY
ScalingCov(aX,bY)=ab·Cov(X,Y) · Var(aX+bY)=a²Var(X)+b²Var(Y)+2ab·Cov(X,Y)
Recipe · Var of aX+bY
  1. Square each coefficient onto its own variance: a²Var(X)+b²Var(Y).
  2. Add cross term 2ab·Cov(X,Y).
  3. Independent? Cov=0 → drop the cross term.
Worked covariance set (σX=10,σY=12,σZ=20; ρXY=.8,ρXZ=−.5,ρYZ=.6)

Cov(X,Y)=.8·10·12=96; Cov(X,Z)=−.5·10·20=−100; Cov(Y,Z)=.6·12·20=144; Cov(2X,3Y)=6·96=576.

Var(X+Y)=100+144+2(96)=436. Var(3X+5Z)=9(100)+25(400)+2·15(−100)=7900.

§14 The Named Discrete DistributionsClass 3 / HW

Binomial — "how many successes in n independent tries?"

Spot it: FIXED n trials · only 2 outcomes (success/fail) · same π each time · trials independent (WITH replacement).

P(X=k)=nCk·πk·(1−π)n−k · E(X)=nπ · Var(X)=nπ(1−π) · SD=√(nπ(1−π))

"At least one" trick: P(X≥1)=1−(1−π)ⁿ. Excel =BINOM.DIST(k,n,π,FALSE/TRUE).

Binomial examples

Salesperson n=25, π=.3: p(8)=25C8·.3⁸·.7¹⁷=.165; E=7.5; SD=√(25·.3·.7)=2.29. Sample bonus π=.267, n=5: P(≥1)=1−.733⁵=.788; P(exactly 2)=5C2·.267²·.733³=.280.

Overbooking — expected value of a binomial function (HW2)

40 rooms, 50 reservations, P(show)=.8 → X~Bin(50,.8); pay $150 per guest over 40. E[comp]=150·Σx=41..50(x−40)P(X=x)=150(1.119)=$167.78.

Poisson — "how many random events in a fixed span?"

Spot it: events at a steady rate over time/space, no upper limit on the count.

P(X=k)=e−λ·λk/k! · E(X)=Var(X)=λ · (SD=√λ) · λ = rate × window
match the windowRescale λ to the interval asked: 4/hr → λ=8 for 2 hours, λ=1 for 15 min. "At least one"=1−e−λ.
Poisson examples (call center, 4/hr)

P(5 in 2 hr): λ=8 → e⁻⁸8⁵/5!=.0916. P(0 in 15 min): λ=1 → e⁻¹=.368. P(≥1 in 1 hr): λ=4 → 1−e⁻⁴=.982. P(≥3), λ=2: 1−e⁻²(1+2+2)=.323.

Hypergeometric — "without replacement" (chances change each draw)

P(X=k)=[C(K,k)·C(N−K, n−k)] / C(N,n)

N=population, K=successes in it, n=draws, k=successes wanted. With replacement→Binomial; without→Hypergeometric.

Hypergeometric examples

Marbles 20 (12R), draw 5: P(3 red)=C(12,3)·C(8,2)/C(20,5)=.397. Acceptance sampling (HW2): ship N=200, inspect 12, reject if any of 10 defectives appears: P(reject)=1−C(190,12)/C(200,12)=.469 (binomial approx 1−.95¹²=.460).

§15 The Normal Distribution & the Z-ScoreClass 4

Bell-shaped, symmetric about μ; two parameters μ (mean) and σ² (variance). Continuous ⇒ P(X=a)=0, so "<" and "≤" are interchangeable. Uniform aside: on [1,5] density height=¼ → P(2≤X≤4)=½.

Standardize — the master moveZ = (X − μ)/σ → look Z up in the exam's normal table (Z~N(0,1))
Recipe · normal probability
  1. Turn each X into a Z: (X−μ)/σ.
  2. Look up P(Z≤z) in the table.
  3. "Greater" → 1 − table. "Between" → subtract the two table values.
Go backwards — find X for a given %X = μ + z·σ  (look up the z for the probability first; z is − below the mean)
Example — Coke demand N(μ=150, σ=20)

P(X≤200): z=2.5 → .9938. P(X≥180): z=1.5 → 1−.9332=.0668. P(150≤X≤180)=.9332−.5=.4332. Stock so P(run out)=.10 → top 10% → z=1.28 → X=150+1.28(20)=176 cans.

§16 Central Limit Theorem — Sums & AveragesClass 4

The CLT: add up (or average) many independent, same-distribution RVs and the result is ≈ Normal — even if each piece is NOT normal. Condition: independent + identically distributed + n large (n ≥ 30). If the pieces are already Normal, it's EXACT for any n.

SUM of nmean = nμ
var = nσ²
SD = σ√n
Z=(T−nμ)/(σ√n)
AVERAGE of n (X)mean = μ
var = σ²/n
SE = σ/√n
Z=(X−μ)/(σ/√n)
sum vs averageSD of a sum = σ√n (grows); SD of an average = σ/√n (shrinks). Standardize with the matching SD. And "n>30 makes an individual value normal" is FALSE — CLT only normalizes the sum/average.
Sum — cars sold

E(X)=1.7, Var=.81. Over 300 days: mean=510, SD=√(300·.81)=15.59. P(<495)=P(Z<−.96)=.168.

Average — branch employees

μ=50, σ=15. n=40: SE=2.37 → P(X>55)=P(Z>2.11)=.017. n=100: SE=1.5 → z=3.33 → .0004.

Corn chips (Sample Exam Q10): μ=11.95, σ=.22, n=100

(a) P(sum>1194): mean=1195, SD=√100·.22=2.2, z=(1194−1195)/2.2=−.45 → P(>)=.675. (b) P(x<11.97): SE=.022, z=.909 → .818. (c) Is one bag Normal because n>30? No — CLT normalizes the average/sum, never a single item.

Normal ≈ BinomialIf nπ>5 and n(1−π)>5, treat Binomial X as Normal with mean=nπ, var=nπ(1−π). Ex: insurance n=1000, π=.06 → mean=60, SD=7.51; P(X<70)=P(Z<1.33)=.908.

§17 The Normal Table — Reading & InterpolatingClass 4

The exam's table gives P(Z ≤ z) = area to the LEFT of z. First turn any question into a Z: z=(X−μ)/σ. The only 4 moves: ① P(Z≤z)=read it straight off · ② P(Z>z)=1−P(Z≤z) · ③ P(Z≤−z)=1−P(Z≤z) (symmetry) · ④ P(a≤Z≤b)=P(Z≤b)−P(Z≤a).

two table styles — check yoursSome tables instead list P(0≤Z≤z) (area from the middle out). Then P(Z≤z)=0.5 + that. Ex: a middle-table 1.35 shows .4115, so P(Z≤1.35)=.5+.4115=.9115. Same answer — just add the 0.5.
Interpolate FORWARD (have z, want area)P(z)=P(z₁)+ (z−z₁)⁄(z₂−z₁) ·[P(z₂)−P(z₁)]
Interpolate BACKWARD (have area, want z)z=z₁+ (A−A₁)⁄(A₂−A₁) ·(z₂−z₁)

Fwd ex: P(Z≤1.234): P(1.23)=.8907, P(1.24)=.8925 → .8907+.4(.0018)=.8914. Back ex: area .90 sits between 1.28(.8997) & 1.29(.9015) → 1.28+.17(.01)=1.282.

§18 "Which Formula?" — the Decision Guide

If the problem says…Use this
"OR", "either", "at least one of A/B"Addition: P(A)+P(B)−P(A∩B)
"AND", "both"Multiplication: P(A|B)·P(B); independent → P(A)·P(B)
"neither" / "only A, not B"1−P(A∪B)  /  P(A)−P(A∩B)
"given", "if… then chance of…"Conditional: P(A|B)=P(A∩B)/P(B)
"reverse the given" (know effect, want cause)Bayes / Total Probability
"how many ways", order matters (ranks)Permutation nPr
"how many ways", pick a group (order NO)Combination nCr
fixed # of yes/no trials, "exactly k / at least"Binomial nCkπk(1−π)n−k; "≥1"=1−(1−π)ⁿ
events over time/space at a rate, no upper limitPoisson e−λλx/x!, λ=rate·time
draw without replacingHypergeometric
"normally distributed", one item, P(X≤…)Z=(X−μ)/σ, then table
"total / sum of n things"CLT sum: mean nμ, SD σ√n
"average / mean of n things"CLT average: mean μ, SD σ/√n
find the value for a target % (e.g. top 10%)X = μ + z·σ (look up z first)
final 3 reminders(1) Sample variance uses n−1. (2) Variances add, SDs never do. (3) CLT normalizes the sum/average, not a single observation.
